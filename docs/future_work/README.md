## Adding a new idea

Create one Markdown file per idea and include:

1. the problem it solves;
2. how it connects to the current pipeline;
3. the proposed pipeline;
4. implementation stages;
5. expected output and validation;
6. open questions and risks.

Keep proposals separate from stable user instructions until they have been implemented and tested.
