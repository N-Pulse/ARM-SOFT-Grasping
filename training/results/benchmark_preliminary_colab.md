# Preliminary model comparison (Colab logs, val split)

**Status: preliminary.** Numbers are copied from the end-of-training validation in the Colab logs,
so they are for monitoring only. The official table is `benchmark_val.md`, generated by
`compare_runs.py` after `eval.py` has run on the dev PC. This file does not replace it.

Common setup: `openimages6` (6 classes; 2080 train, 446 val images, 842 val boxes), 30 epochs,
imgsz 416, batch 32, seed 0, COCO-pretrained, Colab T4, Ultralytics 8.4.163. One run per model.

## Reading so far

- YOLO26s leads on mAP and recall, at about 3.9 times the GFLOPs of YOLO26n.
- The YOLO26n and YOLO11n gap (0.021 mAP50) comes from one run each, so it is not conclusive.
- YOLO26s reused all pretrained weights (708/708) while YOLO26n reused 612/708. This may favour
  YOLO26s over 30 epochs; a cause is not established yet.
